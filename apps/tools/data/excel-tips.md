# Excel 使用小技巧

本文介绍在 Excel 中快速插入间隔空白行的实用方法。

---

## 1、间隔一行插入空白行

**操作步骤：**

1. 在单元格右侧添加两列辅助列
2. 从第二行开始，在对角的位置各输入一个 `1`
3. 选中这四个单元格，下拉填充
4. 使用快捷键 **Ctrl+G**（Mac：**Cmd+G**）打开「定位」对话框
5. 点击「定位条件」→ 选择「空值」
6. 右键 → 选择「插入」→「整行」

即可实现每隔一行插入一个空白行。

---

## 2、间隔两行插入空行

**操作步骤：**

1. 在单元格的第三行后面输入一个 `1`
2. 再间隔一行再输入一个 `1`
3. 选中这四个单元格，下拉填充
4. 与上述步骤相同：**Ctrl+G** → 定位条件 → 空值 → 右键插入整行

即可实现隔两行插入一个空白行。

---

## 3、间隔三行插入空行

**操作步骤：**

1. 从第四行开始输入 `1`
2. 隔两行再输入一个 `1`
3. 选中六个单元格，下拉填充
4. 后续操作同上：定位空值 → 右键插入整行

即可实现隔三行插入一个空白行。

---

## 通用原理

通过辅助列中「1」的分布规律，配合 Excel 的「定位空值」功能，可以快速批量插入任意间隔的空白行，无需逐行手动操作。
